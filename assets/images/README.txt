Food cards use a different local photo for every item: p1-p6 (special pizzas),
m1-m2 (pizza), b1-b2 (burgers), s1 (sandwich), f1-f2 (fries) and c1-c4
(combos). All filenames use the .jpg extension.
The hero uses hero-bg.jpg, cropped from the background photo provided for the
site design reference. hero-pizza.jpg is an optional standalone pizza photo.

The food gallery uses gallery-1.jpg through gallery-8.jpg. These are local,
high-resolution food photos and open in a full-size lightbox when selected.

Other site photos can be added as JPGs:
about-1.jpg, about-2.jpg, about-3.jpg
Missing files show a labelled placeholder instead of a broken image.
